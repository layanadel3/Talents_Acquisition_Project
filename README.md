A web-based recruitment management system developed during a professional training program for **Feyum**. The system is designed to help restaurants and cafés streamline their recruitment process by enabling employers to publish job opportunities, receive applications, manage candidates, and improve hiring efficiency through AI-powered resume matching.

The project combines business analysis, modern web development, project management, and quality assurance to deliver an efficient and user-friendly recruitment platform.
